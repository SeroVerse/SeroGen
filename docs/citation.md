# Citing SeroGen

If you use **SeroGen** in your research, genomic serotyping analyses, or publications, please cite the software using the metadata below.

=== "BibTeX"

    ```bibtex
    @software{Stanton_SeroGen,
      author       = {Stanton, Thomas David},
      title        = {{SeroGen: Genomic analysis for in silico serotyping}},
      url          = {https://seroverse.github.io/SeroGen/},
      repository   = {https://github.com/SeroVerse/SeroGen},
      license      = {GPL-3.0-only}
    }
    ```

=== "APA"

    ```text
    Stanton, T. D. SeroGen: Genomic analysis for in silico serotyping [Computer software]. https://github.com/SeroVerse/SeroGen
    ```
